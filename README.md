# PremiumDownloader-Complete-Java-XML - Android Studio Project (Cloud Build Ready)

This Android project is configured with **GitHub Actions Cloud Build** to compile real, installable Android APKs (`.apk`) and Google Play App Bundles (`.aab`).

## 🚀 How to Build APK on GitHub Cloud (Free):
1. Push this repository to GitHub.
2. Go to the **Actions** tab in your GitHub repository.
3. The **Build Android APK (Cloud Build)** workflow will automatically run.
4. Once completed (approx. 2-3 minutes), download the compiled **app-debug-apk** and **app-release-apk** directly from the **Artifacts** or **Releases** section!
5. Transfer the `.apk` to your Android phone or install via ADB.
